# Example profile overlay

Sift profiles are private overlays on the neutral files in `config/`. A normal
profile is generated by `npm run onboard` and is ignored by version control.
This deliberately generic example is the only profile intended for distribution.
Generated profiles also keep the original dossier, confirmed reader preferences,
an approval preview, and source-candidate/discovery reports inside the private
profile directory.

Try it without creating a profile:

```bash
npm run doctor -- --profile example
```
